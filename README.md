## Pong Remade in Unity

A small remake of the classic Pong made in Unity as a fun side project.

## Features

* Classic Pong gameplay
* Two-player controls
* Ball collision and bounce physics
* Score tracking
* Simple retro-inspired presentation

## Tech Stack

* Unity
* C#

## Controls

| Player       | Controls  |
| ------------ | --------- |
| Left Paddle  | `W` / `S` |
| Right Paddle | `↑` / `↓` |

## Why I Made It

This was a short project to practice Unity fundamentals and finish something small from start to finish. Sometimes rebuilding a simple classic is the fastest way to learn.
